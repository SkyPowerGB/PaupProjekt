# Vehicle Repair Shop Website

> ⚠️ **[Warning]** This project is no longer maintained.

A university ASP.NET MVC5 project developed as an exam assignment.

---

## ✨Features (as remembered)

- User accounts with multiple roles (guest, user, mechanic, admin)  
- Ability to create and manage service requests  
- Receipt creation and download functionality  

---

## ⚠️ Limitations

- UI design is minimal and unpolished  
- Unknown or limited security beyond cookie-based sessions, CSRF tokens, and password hashing  

---

## 📝 Notes

This was an academic project aimed at demonstrating understanding of ASP.NET MVC concepts. Security features are basic and the UI is rough; not intended for production use.
